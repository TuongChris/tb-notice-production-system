# Changelog

## TB-ARCH-v1.0.0 — 2026-09-23

First actually packaged Architecture Specification Pack release after an interrupted previous generation attempt. Seven core specs, source register, a read-only Claude handoff, resolution/acceptance inventories, full checksum manifest and a documentation-only importer.

Explicitly reconciles the frozen JSON-Schema-first API release with the subsequently proposed active Zod-first authoring workflow; preserves public behavior through mandatory parity checks. Adds the missing operation-metadata source, Unicode code-point conversion warning, wire PFC-v1.1 identifier, derived readiness and exact baseline enum names.

Clarifies MySQL shadow/runtime/migration credentials, fixed loopback ports, root environment paths, immutable reference bytes, disabled fixture actor, P0 versus later tests and separate first-PC/CI/second-PC completion.

This is documentation, not P0 implementation, a migration release, current authority review or legal certification. The original Database/API reference is not modified.
