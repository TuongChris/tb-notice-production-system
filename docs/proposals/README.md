# Proposals (inactive)

This folder holds **inactive design proposals**. Nothing here is:

- an accepted decision or an active contract;
- a release record, or a source of generated artifacts;
- an input to any test or tool.

- **Accepted wire releases** live only in `docs/contracts/<release>/` (`amendment.json` + `README.md`), once an approved mission activates them. `tests/contracts/release.ts` composes only the releases it lists.
- **Accepted decisions** live in `docs/decisions/` with the status ACCEPTED.

A proposal becomes active only through its own approved mission: an accepted ADR, a release record, the contract source, generation and parity tests.
